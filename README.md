# Keawgood_Mynovel

โปรแกรมช่วยนักเขียน **MyNovel** ตั้งราคาและตั้งเวลาเผยแพร่ให้ตอนที่เป็น **"ฉบับร่าง"** ทีละหลายร้อยตอน ทำได้หลายเรื่องพร้อมกัน

![icon](assets/icon.png)

## ความสามารถ
- วางลิงก์หน้าคลังตอน (`https://mynovel.co/dashboard/workings/<id>?tab=episode`) ได้ทีละหลายเรื่อง
- ตั้งราคา: ติดเหรียญทุกตอน / ฟรีทุกตอน / ฟรีอัตโนมัติตามกฎ (ลงท้าย 5, 0, ทุก 3 ตอน, กำหนดเอง `1-10, 15`) / ไม่แก้ราคา
- ตั้งเวลา: วันที่-เวลาเริ่ม, วันละกี่ตอน, ห่างกันกี่นาที/ชั่วโมง, ข้ามช่วงเวลา (เช่น 00:00–06:00)
  - "10 ตอน/วัน ห่าง 1 ชม. เริ่ม 15:00" → 15:00 … 00:00 แล้ววันถัดไปเริ่ม 15:00 ใหม่
- ต่อเวลาจากรอบก่อนอัตโนมัติ (รันซ้ำไม่ทับเวลาเดิม)
- จัดเวลาใหม่ให้ตอนที่ตั้งเวลาไปแล้ว + เลือกเริ่มจากลำดับตอนที่ต้องการ
- **ทำพร้อมกันสูงสุด 10 เรื่อง** (Chrome แยกต่อเรื่อง) และซ่อนหน้าต่าง Chrome ได้
- Dry run ดูแผนก่อนบันทึกจริง, ปุ่มหยุด, log ทุกการทำงานในโฟลเดอร์ `logs/`
- **แจ้งเตือนเวอร์ชันใหม่ + กดอัปเดตในโปรแกรมได้เลย**

## สำหรับผู้ใช้ทั่วไป (ไม่ต้องลง Python)
1. ต้องมี **Google Chrome** ในเครื่อง
2. ไปที่ [Releases](https://github.com/Keawgoodx/Keawgood-Mynovel/releases/latest) ดาวน์โหลด `Keawgood_Mynovel-windows.zip`
3. แตกไฟล์ไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น `Documents\Keawgood_Mynovel` (ไม่แนะนำ `Program Files`)
4. เปิด `Keawgood_Mynovel.exe`
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (เพราะโปรแกรมไม่ได้ซื้อใบรับรอง code signing)
5. กด **🔑 เปิดหน้า Login** → ล็อกอิน MyNovel ครั้งแรกครั้งเดียว
6. กด **＋ วางลิงก์เพิ่มเรื่อง** → ตั้งราคา/เวลา → **⚡ เริ่ม**

การล็อกอิน รายชื่อเรื่อง และการตั้งค่า เก็บอยู่ในโฟลเดอร์โปรแกรม (`automation_profile/`, `config.json`) และ **ไม่หาย** เวลาอัปเดต

### อัปเดต
เมื่อมีเวอร์ชันใหม่ โปรแกรมจะขึ้นแถบสีฟ้าด้านบน กด **⬇ อัปเดตเลย** → โปรแกรมดาวน์โหลด ติดตั้งทับ และเปิดใหม่เอง
(กดตัวเลขเวอร์ชันมุมขวาล่างเพื่อตรวจหาอัปเดตเองได้)

## เคล็ดลับ
- ครั้งแรกให้ติ๊ก **Dry run** หรือตั้ง "จำนวนตอนสูงสุด" น้อยๆ ลองก่อน
- รันหลายเรื่องพร้อมกัน: Chrome 1 ตัวใช้ RAM ~300–500 MB แนะนำเลือกหน้าต่าง **ซ่อน (ย้ายออกนอกจอ)**
- ตอนรันหลายเรื่องพร้อมกัน หน้าต่าง Login จะถูกปิดอัตโนมัติ (แต่ละเรื่องใช้สำเนาโปรไฟล์ที่ล็อกอินไว้)

## สำหรับผู้พัฒนา (รันจาก source)
```bat
install.bat             :: ครั้งแรก — สร้าง .venv และติดตั้ง selenium + PyQt6
run.bat                 :: เปิดโปรแกรมจากโค้ด (ไม่มีหน้าต่างดำ)
run_debug.bat           :: เปิดแบบมีหน้าต่างดำ ไว้ดู error
build.bat               :: build .exe อย่างเดียว (ลองเปิดทดสอบใน dist\Keawgood_Mynovel\)
build_and_release.bat   :: build + อัปโหลดขึ้น GitHub ให้เพื่อนอัปเดต (กดอันเดียวจบ)
```

### ออกเวอร์ชันใหม่ให้เพื่อน (3 ขั้น)
1. เพิ่มเลข `__version__` ใน `version.py` (เช่น `2.0.0` → `2.0.1`)
2. เขียนสิ่งที่เปลี่ยนไว้**บนสุด**ของ `release_notes.md` ในหัวข้อ `### ✨ มีอะไรใหม่ใน v2.0.1`
3. ดับเบิลคลิก **`build_and_release.bat`** — โปรแกรมจะ
   build `.exe` → zip → commit + push โค้ด → สร้าง GitHub Release แนบ `Keawgood_Mynovel-windows.zip` + `version.json`
   แล้วเครื่องเพื่อนจะขึ้นแจ้งเตือน "มีเวอร์ชันใหม่" เอง

บังคับทุกเครื่องต้องอัปเดต: `build_and_release.bat --mandatory`

**ครั้งแรกต้องให้สิทธิ์อัปโหลด** (เลือกอย่างใดอย่างหนึ่ง)
- ติดตั้ง [GitHub CLI](https://cli.github.com) แล้วรัน `gh auth login` หรือ
- สร้าง token ที่ https://github.com/settings/tokens?type=beta
  (Repository access: Keawgood-Mynovel · Permissions → Contents: **Read and write**)
  แล้ววาง token ลงไฟล์ `github_token.txt` ในโฟลเดอร์นี้ (ไฟล์นี้ไม่ถูกอัปขึ้น GitHub)

> ⚠️ `automation_profile/`, `config.json`, `logs/`, `github_token.txt` เป็นข้อมูลส่วนตัว — `.gitignore` กันไว้ และ `release.py` ตรวจซ้ำก่อน commit ทุกครั้ง
